# 🌍 TripIntel

> **Transforming Tourism Data into Actionable Insights**

TripIntel is an AI-powered Tourism Intelligence & Analytics Platform designed to help users explore destinations, analyze tourism trends, and make data-driven travel decisions through interactive dashboards and intelligent insights.

---

## ✨ Features

- 📊 Interactive Analytics Dashboard
- 🤖 AI-Powered Tourism Insights
- 🌍 Destination Exploration
- 📈 Data Visualization with Charts
- 🔍 Smart Search & Filtering
- 📍 Tourist Destination Analytics
- 📱 Fully Responsive Design
- 🎨 Modern Glassmorphism UI
- ⚡ Fast & Interactive User Experience

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/vanshita-html/TripIntel.git
```

### Navigate to the Project

```bash
cd TripIntel
```

---

## Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

---

## Backend Setup

```bash
cd backend

python -m venv venv

# Windows
venv\Scripts\activate

# macOS/Linux
source venv/bin/activate

pip install -r requirements.txt

uvicorn app.main:app --reload
```
